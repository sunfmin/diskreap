---
name: diskreap
description: Frees disk space on a Mac by Rules kept in a private gist, deleting only what is provably safe (old, unused, git-ignored, not another user's) — build output like cargo target and node_modules, test leftovers in $TMPDIR, caches, data of uninstalled apps. Use when the user's disk is full, asks to clean up or free space, asks what takes space, wants a new kind of junk cleaned regularly, or mentions diskreap.
---

# diskreap

Run `diskreap --help` and read all of it before anything else. It is the tool's own guide: what it needs, what to run first, how a Rule is written, and why a Rule is added only after the person agrees.
