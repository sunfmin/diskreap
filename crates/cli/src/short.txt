diskreap — deletes what a person agreed to, only when it is safe.

  diskreap doctor                               what is missing, with fixes
  diskreap init                                 make the private gist of Rules
  diskreap plan [--rule ID] [--path P] [--all]  what clean would do; changes nothing
  diskreap clean [--rule ID] [--path P] [--all] delete each Match nothing holds
  diskreap scan                                 large directories no Rule covers
  diskreap rule list|check|add|set|rm           the Rule list in the gist

One JSON object on stdout; events, one a line, on stderr as it walks.
Read `diskreap --help` before the first run.
