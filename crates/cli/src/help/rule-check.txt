diskreap rule check RULE [--all] — what a Rule would match and hold, without adding it.

WHEN   Before rule add: show its answer to the person who decides.
WHO    Anyone. READS the gist and what the Rule matches. WRITES nothing.

  RULE    the Rule as JSON, or `-` to read it from stdin
  --all   every Match, not only the ten largest

ANSWERS
  gist            the gist's id
  rule            the Rule as it would be written
  id_taken        whether a Rule in the list has its id
  same_as_listed  whether that Rule is this one
  plan            what plan answers for one Rule (see `diskreap plan --help`)

TRIPS YOU UP
  A Rule with a fault is an error naming every fault: a glob not starting at
  ~/, $TMPDIR/ or $VARFOLDER/, one that can only reach what the floor keeps,
  `**` with no marker, an unknown key, a bad min_age.
